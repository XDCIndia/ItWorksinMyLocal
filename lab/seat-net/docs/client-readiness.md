## Format for new rows

When adding a client (or updating one), include:
- **Verdict**: one of READY-SEATED-MINTING / READY-NOT-YET-SEATED / NOT-READY / MUST-NOT-SEAT.
- **Evidence**: the specific gate result (mint attribution method used, fair-share numbers, canonical depth, window) — never a log line, never a self-reported head, never `block.miner` on V1. Cite the actual `gate-mint.sh` / `measure-share.py` run if you have one.
- **Open blockers**: issue/PR numbers on the relevant repo, one line each, with the one-sentence "what it fixes" — future operators should not need to re-read the PR to know why it matters.
